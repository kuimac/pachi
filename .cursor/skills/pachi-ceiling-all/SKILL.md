# pachi-ceiling-all

分析結果から天井／遊タイム機を落とさない。詳細手順の本体は skill `pachi-run`。こちらは **天井ある台** の強制ルールだけ。

## いつ使うか

- 朝イチ／午後／期待値／任意の店舗分析を書くとき
- 「天井ある台を全部載せて」と言われたとき
- テンプレに `## 天井ある台` が無い・候補だけになっているのを直すとき

## 必須出力

1. `YYYY-MM-DD/正規店名/天井ある台.md`（`templates/天井ある台.md`）
2. 次の各 MD に `## 天井ある台` セクション  
   `台分析` / `朝イチ狙い目` / `午後狙い目` / `期待値が高い台` / `重要ポイント`
3. 線入りで座る順がある日は `天井狙い目.md`（全台一覧とは別）

## 含め方

- ソース: `python3 tools/brief.py units <店> --day YYYY-MM-DD` の天井／遊タイム列、または全台CSV ∩ 攻略の `has_ceiling_or_yutime`
- **全台**を台番号＋機種で列挙。ハイエナ線入りだけに絞らない
- 非搭載・なし・調査中は除外。店に該当が無いときだけ「該当なし」（セクションは残す）
- 台番号不明なら設置台数＋「現地で台番号確定」。機種サマリだけで全台を消さない

## スクリプト

通常は `python3 tools/analyze_store.py --store <店>`（または `run_pachi.py --analyze`）が `天井ある台.md` と各判断の同名セクションを自動出力する。エージェントはスクリプト結果の欠落確認だけする。

## やらないこと

- 天井ある台を狙い目候補だけに減らすこと
- `## 天井ある台` セクションの省略
- 店舗一覧・攻略全文・docs の通読（数値は `brief.py`。手順は `pachi-run`）
