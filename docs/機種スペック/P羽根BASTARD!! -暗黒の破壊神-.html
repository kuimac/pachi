P羽根BASTARD!! -暗黒の破壊神-

基本情報

項目 内容
メーカー SANKYO
型式名 PH羽根モノバスタードR
タイプ 羽根モノ / 役物機
導入日 2026年11月2日

スペック

項目 内容
賞球 3&5&12
カウント 10カウント
ラウンド 3R/5R/10R（各約1/3）
出玉 約240 / 480＋α / 1080個（払い出し、初回羽根入賞が1R目）
役物確率 約1/13.4（全ルート合算）
羽根開放 1回 約0.4秒 / 2回 約0.4秒×2

スペシャル・ノーマル（外/内）・破天荒の4ルート。3R・5Rは自力継続で最大10R。

天井・遊タイム・LT

項目 内容
天井 非搭載
遊タイム 非搭載
電サポ・確変 非搭載
カウントのリセット 天井・遊タイムがないため、ハマりは次の抽選に影響しない

盤面の場所

常時左打ち。羽根開放と役物内のV入賞が本体。右打ち指示はない。

系列: 羽根モノ（機種ごとの目安。個体差あり）

項目 場所 見方
スタートチャッカー 盤面下部（左右／中央） 入賞で羽根が開く。中央入賞は開放回数が増える機種あり
羽根 役物の上部〜入り口 開放中に玉を役物内へ送る
Vゾーン 役物内（回転体・穴・ホームランVなど） 入賞で大当り。抜けやすい台は即やめ材料
アタッカー 盤面下部中央寄り ラウンド消化。開放を見て打ち出しを合わせる
液晶 盤面中央 ラウンド表示・止め打ち目安。打ち分け指示は出ない
  • 右打ちランプは使わない。常に左打ち。
  • 拾いと役物抜けの台差が大きい。1000円の鳴きとV到達を見て切る。

おすすめカスタム

  • スタンダード／ヒロイン／シンプルから選択可。抽選は変わらない。
  • 演出好みで選ぶ。

打ち方

  • 常時左打ち。スタート入賞→羽根開放→役物でVを狙う。
  • 電サポがないため、大当り後も通常と同じ立ち回り。
  • 遊タイムがないため、深くハマった履歴だけでは拾わない。等価の鳴き目安は1000円あたり約15.5。

総評

羽根モノ。役物約1/13.4、3R/5R/10R均等。自力継続あり。役物・拾いの台差大。遊タイムなし。
