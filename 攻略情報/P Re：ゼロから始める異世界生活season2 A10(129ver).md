# P Re：ゼロから始める異世界生活 season2 A10（129ver.）

大都技研。2026年3月2日導入。型式は P／Re:ゼロから始める異世界生活season2／A10。ライトミドル。遊タイムはない。

## スペック

| 項目 | 内容 |
| --- | --- |
| 大当り確率 | 通常 1/129.9、RUSH中の実質 1/99.9 |
| RUSH | 突入 50%、継続 約70%、ST120回転 |
| 初当り | 300個。50%でRUSH、50%は通常へ |
| RUSH中の出玉 | 1500個 25%、750個 55%、300個 20% |

| 賞球 | 1＆4＆15、10カウント |
| 遊タイム | なし |

初当りそのものは300個で軽い。出玉が乗るのはRUSHに入ったあと、1500個からLTに入れたとき。

## 狙い目

通常時の回転率が17.9以上。19回転以上なら継続候補。

スタートが溜まっていても確率は変わらない。129分の1なので、甘い体感でも100回転以上残ることは普通にある。それを「来そう」と読まない。

LTは通常時から直では入らない。RUSH中の1500個が条件。通常時のハマり台を拾う筋はない。

## やめ時

RUSH終了で通常に戻ったとき。回転率が17.9以上なら通常のまま続けてよい。下ならやめる。

LT中はループが終わるまで消化する。約95%ループなので、1回の300個で切り上げない。

## 朝イチ

閉店スタートは無視して、1000円の実測だけ見る。電サポ120回転の区間を回転率に混ぜると、実際より良く見える。通常時の区間だけで数える。

## 注意

コンプリート機能あり。ボーダーは削りなし・持玉0のシミュレート。右打ちで持ち玉が続けば、必要な回転数は少し下がる。
