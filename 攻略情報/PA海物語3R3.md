# PA海物語3R3

三洋物産。2025年6月2日導入。遊タイムはない。

## スペック

| 項目 | 内容 |
| --- | --- |
| 大当り確率 | 通常 約1/99.9、確変中 約1/16.9 |
| 確変 | 突入 51% / 次回まで |
| 時短 | 40回（チャンスタイム）。引き戻し 約33.1% |
| トータル継続 | 約68.5%（時短引き戻し込み） |
| 賞球 | 3&2&1&4&10 |
| ラウンド | 5R or 10R / 10カウント |
| 出玉 | 5R約500個、10R約1000個 |

| 出玉 | 行き先 | 割合 |
| --- | --- | --- |
| 約1000個（10R） | 確変 | 5% |
| 約500個（5R） | 確変 | 46% |
| 約500個（5R） | 時短40回 | 49% |

甘デジの確変ループ。通常大当り後は必ず時短40回。奇数は確変、偶数は昇格勝負。

## ボーダー

現金・削りなし。1000円あたり。

| 交換 | ボーダー |
| --- | --- |
| 4.00円（等価） | 17.3 |
| 3.57円（28玉） | 19.4 |
| 3.33円（30玉） | 20.8 |
| 3.03円（33玉） | 22.9 |

持玉で回している間は等価側に寄る。朝イチの現金区間は28玉側で見る。


## 狙い目

19.4回転以上。遊タイムはないのでハマりでは狙わない。通常時の回転率だけを見る。

## やめ時

電サポ・RUSHが終わって通常に戻ったとき。回転率が19.4未満なら即やめ。以上なら続けてよい。

## 朝イチ

閉店スタートは使わない。1000円を通常時だけで数え、19.4回転に届かなければやめる。電サポ中の回転は測定に入れない。

コンプリート機能あり。公開解析の概数で、釘と取りこぼしで前後する。
