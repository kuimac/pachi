# P冴えない彼女の育てかた 甘デジ99Ver.

大都技研。2026年2月2日導入。型式は P／冴えない彼女の育てかた／A01。甘デジ。遊タイムはない。

## スペック

| 項目 | 内容 |
| --- | --- |
| 大当り確率 | 通常 1/99.9、右打ちの実質 1/29.6 |
| 冴えてる彼女RUSH | 突入 50%、継続 約67%、ST32回転 |
| 冴えてる彼女RUSH♭ | 継続 約90%、ST66回転 |
| LTの入り方 | RUSH中の大当りの12.5%（約2400個）で♭へ |
| 出玉 | 300個、600個、1200個、2400個 |
| 初当り | 300個。半分がRUSH、半分は通常へ |
| 賞球 | 1＆4＆15 |
| 遊タイム | なし |
| 初当りまでの平均 | 約3.3連、獲得出玉の目安は1400個台 |

2400個は1500個＋300個×3。7図柄は2400個が濃い。

甘デジだからボーダーが低い、ではない。28玉では19.3必要。

## 狙い目

19.3回転以上の台だけ。21回転以上なら甘デジとしても残してよい。

100回転、200回転のハマりは1/99.9なら普通に起きる。救済がないので、深い台を朝から拾わない。

LTの90%は魅力だが、入れるのはRUSH中の12.5%だけ。通常時からLTを待つ打ち方はない。

## やめ時

RUSHとRUSH♭が終わって通常に戻ったとき。回転率が19.3以上なら続け、未満ならやめる。

♭に入っている間は66回転のSTを最後まで消化する。

## 朝イチ

スタートの桁は見ない。1000円で19回転あるかを見る。電サポ32回転と66回転は測定から除く。

15回転前後の台を「そのうち当たる」で粘ると、1000円あたり200円以上のマイナスが積み上がる。

## 注意

コンプリート機能あり。2400個は複数回の払出しの合計で、データカウンターでは連チャンに分かれて見える。
