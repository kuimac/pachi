# P大海物語5スペシャル

三洋物産。2024年11月5日導入。遊タイムは「低確950→時短350」。

## スペック

| 項目 | 内容 |
| --- | --- |
| 大当り確率 | 通常 約1/319.6、確変中 約1/31.9 |
| 確変 | 54% / 次回まで |
| 時短 | 100回（時短中の通常当りは200回＝BIGアシスト） |
| 賞球 | 3&2&1&3&4&15 |
| ラウンド | 10R / 10カウント |
| 出玉 | すべて約1500個 |

確変・時短終了後は通常に戻ったら回転率か遊タイム残りで判断。

大海4SP後継の王道SP。ALL1500個＋遊タイム＋BIGアシスト。

## ボーダー

現金・削りなし。1000円あたり。

| 交換 | ボーダー |
| --- | --- |
| 4.00円（等価） | 17.7 |
| 3.57円（28玉） | 18.7 |
| 3.33円（30玉） | 19.3 |
| 3.03円（33玉） | 20.1 |

持玉で回している間は等価側に寄る。朝イチの現金区間は28玉側で見る。


## 狙い目

18.7回転以上、または遊タイム（低確950→時短350）の残りが浅い台。

## やめ時

電サポ・RUSHが終わって通常に戻ったとき。遊タイム直後でなければ、回転率がボーダー未満なら即やめ。

## 朝イチ

閉店スタートと遊タイム進捗を見る。残りが浅ければ優先。そうでなければ1000円を通常時だけで数え、18.7回転に届かなければやめる。
