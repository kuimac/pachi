# P海物語 極JAPAN

三洋物産。2025年5月7日導入。遊タイムはない。

## スペック

| 項目 | 内容 |
| --- | --- |
| 大当り確率 | 通常 約1/319.6、右打ち中 約1/73.9 |
| ST突入 | 100%（極ノ刻50% / 極チャンス50%） |
| 極ノ刻 | ST100+残保留4 / トータル突入 約64% / 継続 約76% |
| 極チャンス | ST20+残保留4 / 引き戻し 約28% |
| 賞球 | 3&1&1&3&5&15 |
| 出玉 | 2R約300個、10R約1500個（右打ち中20%は約3000個+上乗せ） |

初当り後は必ず右打ち。極ノ刻終了後は通常に戻ったら回転率で判断。

新生JAPANの海ST。初当りALL1500個。遊タイムなし。

## ボーダー

現金・削りなし。1000円あたり。

| 交換 | ボーダー |
| --- | --- |
| 4.00円（等価） | 18.4 |
| 3.57円（28玉） | 20.6 |
| 3.33円（30玉） | 22.1 |
| 3.03円（33玉） | 24.3 |

持玉で回している間は等価側に寄る。朝イチの現金区間は28玉側で見る。


## 狙い目

20.6回転以上。遊タイムはないのでハマりでは狙わない。通常時の回転率だけを見る。

## やめ時

電サポ・RUSHが終わって通常に戻ったとき。回転率が20.6未満なら即やめ。以上なら続けてよい。

## 朝イチ

閉店スタートは使わない。1000円を通常時だけで数え、20.6回転に届かなければやめる。電サポ中の回転は測定に入れない。

コンプリート機能あり。公開解析の概数で、釘と取りこぼしで前後する。
