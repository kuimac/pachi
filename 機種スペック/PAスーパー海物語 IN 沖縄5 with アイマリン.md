# PAスーパー海物語 IN 沖縄5 with アイマリン

| 項目 | 内容 |
| --- | --- |
| メーカー | 三洋物産 |

| 導入日 | 2021年9月6日 |

## スペック

| 項目 | 内容 |
| --- | --- |
| 大当り確率 | 通常 約1/99.9、ST中 約1/9.9 |
| ST | 突入 100% / 5回 |
| 電サポ | 25 or 50 or 100回転 |
| 賞球 | 3&2&3&4&11 |
| 出玉 | 5R約550個、10R約1100個 |

電サポ終了後は通常に戻ったら回転率で判断。

## 天井・遊タイム・LT

| 項目 | 内容 |
| --- | --- |
| 天井 | 非搭載 |
| 遊タイム | 非搭載 |
| カウントのリセット | 天井・遊タイムがないため、ハマり回転数は次の抽選に影響しない |

## 打ち方

- 通常時は左打ち（右打ち指示が出たら従う）。
- 電サポ中・RUSH中は打ち切る。通常に戻ったら回転率を見て継続かやめを決める。
- 遊タイムがないため、深くハマった履歴だけでは拾わない。等価の目安は1000円あたり約18.3回転。

## 総評

沖海5アイマリン甘デジ。ST5。遊タイムなし。
