## スペック

| 項目 | 内容 |
| --- | --- |
| 大当り確率 | 通常 約1/319.6、確変中 約1/31.9 |
| 確変 | 60% / 次回まで |
| 時短 | 100回（ジンベェタイム中の通常は200回） |
| ジンベェタイム込継続 | 約78.8% |
| 賞球 | 3&2&5&15 |
| ラウンド | 2R or 10R / 10カウント |
| 出玉 | 2R約60個、10R約1500個 |

通常時（ヘソ）は 10R確変40% / 2R確変20% / 10R通常+時短100 40%。電サポ中の一部でジンベェタイムへ。

## 天井・遊タイム・LT

| 項目 | 内容 |
| --- | --- |
| 天井 | 非搭載 |
| 遊タイム | 非搭載 |
| カウントのリセット | 天井・遊タイムがないため、ハマり回転数は次の抽選に影響しない |

## 打ち方

- 通常時は左打ち（右打ち指示が出たら従う）。
- 電サポ中・RUSH中は打ち切る。通常に戻ったら回転率を見て継続かやめを決める。
- 遊タイムがないため、深くハマった履歴だけでは拾わない。等価の目安は1000円あたり約17.4回転。

## 総評

沖海シリーズ最新。確変60%にジンベェタイムで時短200回が付く。遊タイムなし。
