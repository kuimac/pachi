## スペック

| 項目 | 内容 |
| --- | --- |
| 大当り確率 | 通常 約1/319.6、確変中 約1/31.9 |
| 確変 | 54% / 次回まで |
| 時短 | 100回（時短中の通常当りは200回＝BIGアシスト） |
| 賞球 | 3&2&1&3&4&15 |
| ラウンド | 10R / 10カウント |
| 出玉 | すべて約1500個 |

確変・時短終了後は通常に戻ったら回転率か遊タイム残りで判断。

## 天井・遊タイム・LT

| 項目 | 内容 |
| --- | --- |
| 天井 | 非搭載 |
| 遊タイム | 低確率950回転 → 時短350回転 |
| カウントのリセット | 遊タイム到達で時短。当りを挟むとカウントはリセット |

## 打ち方

- 通常時は左打ち（右打ち指示が出たら従う）。
- 電サポ中・RUSH中は打ち切る。通常に戻ったら回転率を見て継続かやめを決める。
- 遊タイムがある。等価の目安は1000円あたり約17.7回転。

## 総評

大海4SP後継の王道SP。ALL1500個＋遊タイム＋BIGアシスト。
