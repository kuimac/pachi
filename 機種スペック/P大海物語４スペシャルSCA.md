## スペック

| 項目 | 内容 |
| --- | --- |
| 大当り確率 | 通常 約1/199.8、ST中 約1/40.6 |
| ST | 突入 100% / 51回（電サポ50） / 継続 約72% |
| 賞球 | 3&2&2&4&15 |
| ラウンド | 3R or 5R or 10R / 10カウント |

振り分けは 10R 30% / 5R 30% / 3R 40%。初当り後は必ずST。

## 天井・遊タイム・LT

| 項目 | 内容 |
| --- | --- |
| 天井 | 非搭載 |
| 遊タイム | 非搭載 |
| カウントのリセット | 天井・遊タイムがないため、ハマり回転数は次の抽選に影響しない |

## 打ち方

- 通常時は左打ち（右打ち指示が出たら従う）。
- 電サポ中・RUSH中は打ち切る。通常に戻ったら回転率を見て継続かやめを決める。
- 遊タイムがないため、深くハマった履歴だけでは拾わない。等価の目安は1000円あたり約18.7回転。

## 総評

大海BLACK系のフルST。遊タイムなし。ST終了まで打ち切る。
