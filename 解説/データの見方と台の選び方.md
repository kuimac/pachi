# データの見方と台の選び方

台のデータで何を見て、どの順で座るか。このサイトの午後・朝イチ判断も同じ順。

## 結論（先にこれ）

| 順 | 見るもの | 座るか |
| --- | --- | --- |
| 1 | **右打ち残し**（履歴の短間隔＋現在スタート＋**液晶が右**） | 右なら最優先。通常画面なら切る |
| 2 | **1000円実測**（現金1000円＝250玉で何回転したか） | ボーダー以上なら候補 |
| 3 | **遊タイム／天井までの残り** | 拾い線に入っていれば候補 |
| 4 | それ以外 | **見送り** |

差玉ランキング上位・前日の出玉・ハマり深さだけで座らない。空席はデータに出ないので、現地の座りを優先する。

## 収益を最大化するとき、何が効くか

長期の収支は「当たる／当たらない」一発より、**入れる台・やめるタイミング・交換条件**の積み重ねで決まる。関わる要素を、打つ人と店側のどちらが決められるかに分ける。打つ人は **自分ができることだけ** に力を使い、店側が決めた条件は選ぶ・測る・避ける側に回る。

### 関わる要素と、誰がコントロールするか

| 要素 | 収支への効き方 | 打つ人 | 店側 |
| --- | --- | --- | --- |
| **台選び（右残し・実測・遊タイム）** | 期待値がプラス側の局面だけ座る | **できる**（どの台に座るか） | 配置・島構成は決められるが、客の着席先は決められない |
| **1000円実測とボーダー判定** | 遅い台への追加投資を止める | **できる** | できない |
| **やめ時（通常戻り・ボーダー割れ）** | 負けを伸ばさない | **できる** | できない |
| **投資上限・退店判断** | その日・その時間帯の損失上限 | **できる** | できない |
| **交換単価（玉数）・貸出価格** | 同じ出玉でも換金額が変わる | **店選びではできる**（着席後は固定） | **できる**（レート・貸出帯を設定） |
| **導入機種・台数** | 打てるスペックの選択肢 | **店・機種選びではできる** | **できる**（何を何台入れるか） |
| **機種スペック本体（大当り確率・ST等）** | 1回転あたりの当りやすさの土台 | 変更不可（選ぶだけ） | **変更不可**（型式で固定。営業中に上げ下げできない） |
| **ヘソの入りやすさ（釘・盤面まわり）** | 同じ投資でもスタート回転が変わる | **できない**（測って受けるだけ） | **盤面側は店の領域**（ただし営業中の自由な打ち替えは法令・自治体運用で制限が強い） |
| **乱数・当り外れ（その1回転）** | 短期の出玉の上下 | **できない** | **できない** |
| **空席・他の客の打ち終わり** | 残し台に座れるか | **ほぼできない**（早めに回る程度） | 台数・レイアウト以外は **ほぼできない** |
| **データ公開・更新（Site Seven等）** | 判断材料の精度 | **できない**（取れた範囲で決める） | 連携・掲載範囲に **一部関与**（詳細は情報会社側も大きい） |
| **営業時間・入場・コンプリート** | 打てる時間・打ち止め | **できない**（従う／別店へ行く） | **できる** |

### 説明（使い方）

- **打つ人の最大化の本体は、打つ人列が「できる」行だけ。** 右残しを拾う、ボーダー未満で切る、遊タイム未達を追わない、交換が不利な店を避ける。
- **店側ができること（交換・貸出・導入・釘・営業）は、対抗せず条件として扱う。** 遅い釘は止められないが、測って切れる。交換が悪い店は行かない／数字を店に合わせる。
- **ヘソの入りやすさ（回転の出方）と、当たる確率は別物。** 下の小節を見る。
- **スペックそのものは誰もその場で変えられない。** 店は導入機種を選び、打つ人は「その機種のボーダーと拾い線」で判断する。
- **できない列（乱数・他客・取れないデータ）を理由に伸ばさない。** 「当たる気がする」「ここまで入れた」は次の1回転の期待値を変えない。
- このページの選び順（右残し → 実測 → 遊タイム → 見送り）は、打つ人ができることだけを優先順位に並べた手順。

### ヘソの入りやすさと、当たる確率

混同しやすいので分ける。

| 何か | 操作できるか | 当日リアルタイムで変えられるか |
| --- | --- | --- |
| **ヘソの入りやすさ**（スタートの出やすさ・回転率） | 打つ人は **不可**。店側は盤面・釘まわりの領域（調整の可否・タイミングは法令・公安委員会等の運用に従う） | **営業中に客の目の前で自由に変える前提では組まない。** 日によって速い／遅い差は出るので、打つ人は **1000円実測** でその時点の出方だけ見る |
| **大当り確率**（例: 通常 1/349.9） | 打つ人も店側も **不可**。型式・主基板側で固定 | **不可。** 営業中に確率を上げ下げする操作はできない（不正） |
| **その1回転が当るか** | どちらも **不可**（乱数） | **不可** |

戦略上の意味:

- 「当たりやすくされた／されにくくされた」と感じても、**内部確率が変わったと読まない。** まず疑うのは回転の出方（ヘソ・電チューまわりの実測）。
- 打つ人ができる対応は、確率いじりではなく **遅い台を切る／速い台だけ残す**。右残し・遊タイムの話とも別レイヤー。

## 画面で必ず確認する

データは「候補を絞る道具」。最終判断は液晶。

| 画面 | 意味 | 打ち方 |
| --- | --- | --- |
| 右打ち指示・電サポ中 | ST／時短／RUSHの残りがあるかも | 残し確認の対象 |
| 通常（左打ち） | 残しは消えている | スタートが浅くても切る |
| 電源持ち越し不明 | 朝イチは特に当てにならない | 目視してから決める |

## データの見方（項目ごと）

### 大当り履歴（いちばん大事）

| 見方 | 読み |
| --- | --- |
| 短時間に当りが続く | 右打ち側の連チャン。残し候補 |
| 最後の当り時刻と現在スタート | ST／時短の枠から残り回転を概算 |
| 大きなスタート差のあと1発 | 通常からの初当り寄り。その後の現スタートが右か通常かは画面次第 |
| 履歴が取れない（有料壁） | 一覧の現スタートとチャンス中当り回数だけで弱く判定。無理に座らない |

### 現在スタート／スタート

| 見方 | 読み |
| --- | --- |
| 連チャン直後でスタートが浅い | 右なら残し。通常なら価値なし |
| ST枠ちょうど（例: 157や144） | 駆け抜け直後の線が濃い。画面確認 |
| 深いスタートだけ | ハマり理由では座らない（天井非搭載なら特に） |

### 累計スタート・大当り回数・初当り

| 見方 | 読み |
| --- | --- |
| 大当りが多い／最高出玉が大きい | 「よく出た台」。もう消化済みのことが多い |
| 初当りと大当りの差 | 連チャンの厚みの目安。残し判定の補助 |
| 累計だけ見て浅い／深い | 単独では選ばない |

### 差玉・出玉ランキング

参考までに見る。**現スタートと履歴が取れないなら席取り根拠にしない。**

### 遊タイム／天井カウント

| 見方 | 読み |
| --- | --- |
| 残りが拾い線（機種の狙い目回転）に入っている | 投資が見合うなら候補 |
| まだ遠い | 見送り |
| 非搭載 | ハマりを理由にしない |

機種ごとの枠・ボーダー・拾い線は [攻略情報](../index.html#guide) と [機種スペック](../index.html#spec) を見る。

## 選び方の手順（現場）

1. 店舗の **午後狙い目／朝イチ狙い目／重要ポイント** を開く。
2. 表の上から、扱いが「右打ち残し確認」の台へ行く。
3. 液晶が右なら座る。通常なら次の残し候補へ。残しが全部通常なら次段へ。
4. **1000円実測** 候補があれば、通常時だけ測る。ボーダー未満なら切る。
5. 遊タイムが拾い線なら候補。未達なら切る。
6. どれもダメなら、その時間帯はその店を切る。

朝イチは、前日最終の残し・持ち越しを **重要ポイント** で先に見る。回転率の順より画面が先。

## やらない選び方

| やりがち | なぜやらない |
| --- | --- |
| 差玉1位に飛びつく | 出たあとのことが多い |
| 「浅いから」だけで座る | 通常戻りならただの浅い |
| 「深いから天井近い」 | 非搭載なら近づかない |
| 端台・時間帯・隣台 | 抽選とは無関係（[オカルト一覧](../機種スペック/オカルトパチンコ動作一覧.md)） |
| 有料データの中身を推測して座る | 取れていない根拠は使わない |
